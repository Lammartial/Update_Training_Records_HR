
# Training Evidence Automation

Python-based automation for processing training evidence PDF files, extracting information from QR codes, updating Training Evidence workbooks, and generating the final Training Record.

The project consists of several scripts that form a sequential processing pipeline:

### Automated execution

For normal use, the entire workflow can be started from a single file:

```text
HR_TRAINING_AUTOMATION.pyw
```

The launcher provides a GUI with two options:

- **Create NEW Training Evidence** → uses `QR_scan_new.py`
- **UPDATE Existing Training Evidence** → uses `QR_scan_update.py`

After the user selects an option, the launcher automatically:

1. Checks `requirements.txt` and installs the required Python libraries if needed.
2. Runs the selected QR scan script.
3. Waits for the script to finish and for Excel/file operations to complete.
4. Runs `HR_import2_V5.4_GUI_v3`.
5. Runs `HR_SCRIPT1_V8`.
6. Displays the live output/log of the scripts in the GUI.
7. Stops the process if any step fails.

The launcher file and `requirements.txt` should be kept in the same folder as the three processing scripts.

## 1. Project Purpose

The purpose of this project is to automate the processing of training evidence documents used by HR.

Training evidence is initially stored as PDF files containing QR codes. The QR codes contain information such as:

* Training number
* Training content
* Training details
* Training material number
* Training start time
* Training end time
* Training duration
* Trainer information
* Trainee employee IDs
* Trainee names
* Control QR information

The extracted information is progressively transformed into structured Excel files that are eventually used to generate the company's Training Record.

# 2. Processing Workflow

The project consists of four main processing stages.

## Step 1 — QR Scan: Full Import

### Script

```text
QR_scan_new.py
```

### Input

* Training Evidence Excel template
* Folder containing training evidence PDFs

Example:

```text
2026.6.9 Training_Evidence.xlsx
PDF_to_import/
├── 971.pdf
├── 972.pdf
├── 973.pdf
└── ...
```

### Process

The script:

1. Opens the Training Evidence Excel template.
2. Scans all PDF files in `PDF_to_import`.
3. Detects QR codes across all pages.
4. Extracts training information.
5. Extracts trainer information.
6. Extracts trainee information.
7. Validates the control QR.
8. Creates one worksheet for each training PDF.
9. Names worksheets using:

```text
Training_<Training_No.>.pdf
```

Example:

```text
Training_971.pdf
Training_972.pdf
Training_973.pdf
```

10. Creates/updates the `SUMMARY` sheet.
11. Saves the resulting Training Evidence workbook.

### Output

```text
Training_Evidence.xlsx
```

containing:

```text
SUMMARY
Training_971.pdf
Training_972.pdf
Training_973.pdf
...
```

# 3. QR Scan: Incremental Update

## Script

```text
QR_scan_update.py
```

This script is intended for situations where a large number of PDFs have already been processed and new training evidence PDFs are added later.

### Input

An existing `Training_Evidence.xlsx` generated by `QR_scan_new.py` or a previous execution of `QR_scan_update.py`.

The script also scans:

```text
PDF_to_import/
```

### Incremental Processing Logic

The script checks the `SUMMARY` sheet.

For each PDF in `PDF_to_import`:

| Condition                       | Action     |
| ------------------------------- | ---------- |
| PDF does not exist in SUMMARY   | Scan PDF   |
| PDF exists and Status = `OK`    | Skip PDF   |
| PDF exists and Status = `ERROR` | Rescan PDF |

For example:

```text
SUMMARY

PDF_File     Status
--------------------
971.pdf      OK
972.pdf      OK
973.pdf      ERROR
974.pdf      OK
```

If the folder contains:

```text
971.pdf
972.pdf
973.pdf
974.pdf
975.pdf
976.pdf
```

the script will:

```text
971.pdf  → SKIP
972.pdf  → SKIP
973.pdf  → RESCAN
974.pdf  → SKIP
975.pdf  → SCAN
976.pdf  → SCAN
```

### Rescanning an ERROR File

If a PDF previously failed:

```text
973.pdf → ERROR
```

the script should:

1. Remove the previous `Training_973.pdf` worksheet.
2. Rescan the PDF.
3. Recreate the worksheet.
4. Update the corresponding row in `SUMMARY`.

This prevents duplicate worksheets.

# 7. QR Code Processing

The QR scanning process is designed to handle training evidence PDFs containing multiple pages.

A training PDF can contain:

* Multiple trainee pages
* Pages without QR codes
* Trainer QR
* Control QR
* QR codes spanning different pages

The scanner should scan all pages rather than assuming that:

```text
Page 1 = trainee
Page 2 = trainer
Last page = control QR
```

The current implementation therefore attempts to identify QR content based on the QR payload and its position/order rather than relying solely on the page number.

---

# 8. Control QR

A control QR is used to validate QR detection.

Example:

```text
CHK1|ALG=COUNT|VAL=10
```

This means that the PDF is expected to contain:

```text
10 non-control QR codes
```

The control QR itself is excluded from this count.

The scanner compares:

```text
Expected non-control QR count
```

against:

```text
Actually detected non-control QR count
```

If they match:

```text
Status = OK
```

Otherwise:

```text
Status = ERROR
```

This helps identify PDFs where QR detection may have failed.

# 9. Excel Sheet Sorting

The generated Training Evidence workbook may contain many worksheets:

```text
Training_971.pdf
Training_1001.pdf
Training_982.pdf
Training_1010.pdf
...
```

Excel's default worksheet ordering is not necessarily numerical.

A VBA macro can be used to sort the worksheets.

## VBA Macro

Open the workbook in Excel.

Then:

1. Press `Alt + F11`.
2. Go to `Insert` → `Module`.
3. Paste the following code:

```vb
Sub SortSheetsAscending()

    Dim i As Long
    Dim j As Long

    Application.ScreenUpdating = False

    For i = 1 To Sheets.Count - 1
        For j = i + 1 To Sheets.Count

            If UCase(Sheets(j).Name) < UCase(Sheets(i).Name) Then
                Sheets(j).Move Before:=Sheets(i)
            End If

        Next j
    Next i

    Application.ScreenUpdating = True

    MsgBox "Sheets sorted successfully!", vbInformation, "Done"

End Sub
```

4. Run `SortSheetsAscending`.

> Note: This performs a lexical/alphabetical comparison of worksheet names. If strictly numerical ordering of `Training_2.pdf`, `Training_10.pdf`, etc. is required, the macro should be enhanced to extract and compare the numeric Training No.

# 10. Recommended Processing Order

## Recommended: use the automated launcher

For normal operation, run:

```text
HR_TRAINING_AUTOMATION.pyw
```

Then select either **Create NEW Training Evidence** or **UPDATE Existing Training Evidence**. The launcher automatically executes the required three scripts in the correct order and shows the live processing log.

### Manual processing

The individual scripts can still be run manually when troubleshooting or testing. The recommended order is:

```text
Step 1
QR_scan_new.py
        │
        ▼
Training_Evidence.xlsx
        │
        ▼
Step 2
QR_scan_update.py
        │
        ▼
Updated Training_Evidence.xlsx
        │
        ▼
Step 3
HR_import2_V5.4_GUI_v3
        │
        ▼
Training_evidence_scan.xlsx
        │
        ▼
Step 4
HR_SCRIPT1_V8
        │
        ▼
Training_Record.xlsx
```

For subsequent batches of training PDFs, **do not run `QR_scan_new.py` again** unless a complete rescan is required.

Instead use:

```text
QR_scan_update.py
```

so that successfully processed PDFs can be skipped.

# 10.1 Python Requirements

`requirements.txt` is stored together with the automation scripts.

`HR_TRAINING_AUTOMATION.pyw` checks this file after the user selects a processing mode and runs:

```text
python -m pip install -r requirements.txt
```

The installation output is shown in the launcher's Process Log. Normally, there is no need to install the packages manually.

# 11. Important Operational Notes

Before running the scripts:

1. Verify that the correct Training Matrix is being used.
2. Verify that Master Data is up to date.
3. Verify that the PDF files in `PDF_to_import` are the intended source documents.
4. Review the `SUMMARY` sheet after QR scanning.
5. Investigate all PDFs with:

```text
Status = ERROR
```

6. Review suspicious employee IDs.
7. Review Vector Value and Active Flag results before generating the final Training Record.
8. Keep backups of previous Training Evidence and Training Record files.
